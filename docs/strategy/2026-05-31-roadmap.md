# StockPilot Roadmap — 2026-05-31

From a full-system audit (workflow wmrvit6ly). System is broadly complete; this is the prioritized backlog of what's left. Execution order: P0 → P1 → P2.

## P0 — go-live correctness/security (close before relying on shipping / multi-org in prod)
1. **Wire `reconcilePurchasing` → admin endpoint + reaper cron.** Stuck-shipment recovery is tested but reachable from no route/cron; a crash mid-buy strands an order's shipping permanently. Add `POST /api/v1/orders/[id]/shipping/reconcile` (shipping:manage) + a daily cron reaping `carrier_shipments` stuck in `purchasing` (age > 30min). *(small)*
2. **CI must run the tests.** `ci.yml` only typechecks+builds; 67 test files never execute → a cross-org RLS regression could ship undetected. Add the test step + gate. *(small)*
3. **AAL2 on `setModuleEnabledAction`.** Privileged module toggles only check role, not AAL2 — an AAL1 admin in an mfa-required org bypasses the gate. *(small)*
4. **`.env.local.prod` off the working tree.** Plaintext prod secrets on disk (gitignore blocks re-commit post the 2026-05-17 incident, but the file is a liability). Move to Vercel env vars + add a CI guard rejecting non-placeholder `.env`. *(small; relocation is a USER action)*
5. **Verify + meter the public `/r/[token]` order rate-limit.** Unauthenticated endpoint that writes order_requests; confirm the 0048 limiter wraps it + add an abuse metric. *(small)*
6. **Connector dead-letter operator view + replay.** Failed QBO/EasyPost events dead-letter into `connection_sync_log` with no UI/replay — exports silently fall behind after a bad token/account-id. Add a read-only list + a replay action. *(medium)*

## P1 — highest value for the domain (schools buying books)
1. **CSV/report export UI** — endpoints exist (`inventory/export.csv`, `reports/[slug]/csv`); wire export buttons across report/list surfaces + add order-history export. *(small, top value-to-effort)*
2. **Order-model ADR: `order_requests` vs `sales_orders`** — unblocks every ecommerce connector (Square/Shopify/Amazon). Recommend a distinct `sales_orders` concept. *(medium decision)*
3. **Returns / RMA** — entirely missing; damaged/wrong-title/end-of-year book returns; reconcile against inventory + QBO; optional EasyPost return label. *(large)*
4. **Reorder automation** — forecasting + suggestions exist; add one-click "draft PO from suggestions" (group by supplier, prefill to reorder point). *(medium)*
5. **Event-driven notifications** — fire push/in-app on PO-received / order-ready / low-stock; mobile Realtime subscribe. *(medium)*
6. **Mobile multi-org SQLite wipe on org switch** — must land before onboarding a 2nd org. *(medium)*

## P2 — polish / later
- pgTAP tests for SECURITY DEFINER RPCs *(large)*; audit-log trigger on `organization_modules` toggles *(small)*; QBO chart-of-accounts picker (replace free-text IDs) *(medium)*; requester order-history view *(medium)*; serial-number capture UI *(medium)*; connector/DR runbooks *(small)*; mobile EAS hardening (hardcoded buildNumber, add eas-cli, document the query-string@7.1.3 gotcha) *(small)*.
- **Parked (off critical path):** Square / Shopify / Amazon connectors (gated by the order-model ADR); the SWR client data cache (await real contention data).
